# DIGIHAZ PhD Course — Student Notebooks

## How to use this repository

1. **Fork** this repository into your own GitHub account
2. Open exercises using the Colab badges in [digihaz-course-materials](https://github.com/Digihaz/digihaz-course-materials)
3. Work in your fork — never commit to this shared repository
4. Submit your fork URL via Moodle at the end of each module

## Structure

One `exercise.ipynb` per topic, pre-structured with metadata, setup cells, and task sections.
